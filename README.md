# CARCERIA — Sürümler

Bu depo yalnızca **CARCERIA**'nın yayınlanmış Windows sürümlerini barındırır. Oyunun kodu burada değildir.

- Oyun yeni sürümleri bu depodan **otomatik** olarak indirir; ana menüde bildirim çıkar.
- Elle kurmak için **Releases** bölümündeki en son `CARCERIA-Setup-x.y.z.exe` dosyasını indir.
- Güncellemeler kayıtlarını silmez (`%APPDATA%\CARCERIA\saves`).
